## Proyectos destacados
 
### BRP Capstone
ERP para gestión de proyectos de construcción. API RESTful modular en Node.js/Express bajo arquitectura por capas (rutas, controladores, servicios), con Firestore como base de datos. Integra el gateway de pago Transbank y funciones de inteligencia artificial con Vertex AI. Seguridad reforzada con Helmet.js, CORS, Rate Limiting y RBAC. Documentada con Swagger/OpenAPI y testeada con Jest/Supertest.
 
### GreenTrace
Plataforma de trazabilidad industrial con asistente conversacional de inteligencia artificial. Backend serverless en Firebase Cloud Functions v2. Construí el asistente con Google Genkit y Vertex AI (Gemini 2.5 Flash), definiendo más de 10 herramientas funcionales para interacción bidireccional con la base de datos, además de triggers automáticos de Firestore y RBAC mediante Custom Claims.
 
### SAGD
Sistema de gestión documental serverless. Backend en Node.js y Firebase Cloud Functions v2, con versionado de documentos mediante copias profundas de subcolecciones y metadata para trazabilidad histórica. Arquitectura event-driven (Firestore Triggers) para borrado en cascada y limpieza de archivos en Storage.
