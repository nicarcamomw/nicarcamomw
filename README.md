## Proyectos destacados

- **BRP Capstone:** ERP para gestión de proyectos de construcción. API RESTful modular construida con Node.js y Express bajo arquitectura por capas (rutas, controladores, servicios), con Firestore como base de datos, integración del gateway de pago Transbank (Webpay Plus / Oneclick) y funciones de inteligencia artificial con Vertex AI. Seguridad implementada con Helmet.js, CORS, Rate Limiting y RBAC. Documentada con Swagger/OpenAPI y testeada con Jest y Supertest.

- **GreenTrace:** Plataforma de trazabilidad industrial con asistente de inteligencia artificial. Backend serverless desarrollado con Firebase Cloud Functions v2. Lideré la construcción de un asistente conversacional con Google Genkit y Vertex AI (Gemini 2.5 Flash), definiendo más de 10 herramientas funcionales para interacción bidireccional con la base de datos. Incluye triggers automáticos de Firestore y control de acceso por roles (RBAC) mediante Custom Claims.

- **SAGD:** Sistema de gestión documental serverless. Backend construido con Node.js y Firebase Cloud Functions v2, con un sistema de versionado de documentos mediante copias profundas de subcolecciones y metadata para trazabilidad histórica. Arquitectura event-driven (Firestore Triggers) para borrado en cascada y limpieza asociada de archivos en Storage.
